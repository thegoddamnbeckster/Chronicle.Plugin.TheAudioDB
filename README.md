# Chronicle.Plugin.TheAudioDB

Metadata provider plugin for **TheAudioDB**.

## Design Document

Full design documentation:
[docs/plugins/PLUGIN_THEAUDIODB.md](https://github.com/thegoddamnbeckster/Chronicle/blob/develop/docs/plugins/PLUGIN_THEAUDIODB.md)

## Supported Media Types

`music`, `album`, `artist`

## Quick Start

1. `dotnet build`
2. Copy `Chronicle.Plugin.TheAudioDB.dll` to your Chronicle `plugins/active/` directory
3. Restart Chronicle
4. Navigate to **Settings -> Plugins -> TheAudioDB**
5. Configure required settings (see design doc)
